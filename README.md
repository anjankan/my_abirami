# Item photos

Put one real photo per item in this folder. The app picks them up automatically.
Use plain `.jpg` files named exactly like this:

| File name           | Item                  |
|---------------------|-----------------------|
| tomato.jpg          | தக்காளி / Tomato        |
| onion.jpg           | வெங்காயம் / Onion        |
| potato.jpg          | உருளைக்கிழங்கு / Potato   |
| carrot.jpg          | கேரட் / Carrot          |
| banana.jpg          | வாழைப்பழம் / Banana      |
| greenbanana.jpg     | வாழைக்காய் / Green Banana |
| rice.jpg            | அரிசி / Rice            |
| dal.jpg             | துவரம் பருப்பு / Toor Dal |
| milk.jpg            | பால் / Milk             |
| egg.jpg             | முட்டை / Egg            |
| coconut.jpg         | தேங்காய் / Coconut       |
| oil.jpg             | எண்ணெய் / Oil           |
| sugar.jpg           | சர்க்கரை / Sugar        |

Tips:
- Take the photo close-up on a plain background, in daylight.
- Any size works; the app shows them small.
- Until a file exists, the item shows its emoji.
- Items added in the app can also get a photo by tapping the picture in the Prices screen.
- After adding or changing files, commit and push them to GitHub, then reload the app.
